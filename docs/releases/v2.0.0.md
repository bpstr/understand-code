# Understand Code 2.0.0

Understand Code now runs on **Node.js 22 or newer**, with a strict TypeScript source tree and compiled JavaScript in every installable package. Python is no longer needed to install, run, build or test the skill. The runtime has no npm dependencies.

## Documentation and specifications

- Generate audience-focused reference, how-to, tutorial, explanation and specification pages with explicit scope and maintenance triggers.
- Write structured behavioral contracts, ordered procedures, tables and literal examples with exact source evidence.
- Distinguish observed behavior, existing specified requirements, unapproved proposals and unknowns. Stable requirement IDs connect the source, rationale and verification plan.
- Keep example checks honest: unexecuted, syntax/schema checked and externally behavior-checked examples remain distinct and source/content bound.
- Use `verify --require-doc-quality` for a separate structural documentation-readiness gate. Human source review remains necessary; a passing fixture or gate is not proof of semantic truth.

## Change coverage and preservation

The release also includes source-qualified concepts and occurrences, independent semantic scopes, retained baseline/target obligations, reviewed change ledgers, five coverage axes, and the pinned Change Knowledge Exchange v1 format. Source hashes, stale-claim quarantine, conflict history, protected maintainer notes and transactional output replacement remain part of the contract.

## Installation and migration

Install the standalone CLI from this release's npm archive:

```bash
npm install --global https://github.com/bpstr/understand-code/releases/download/v2.0.0/understand-code-2.0.0.tgz
understand-code --version
```

Existing Claude/Codex plugin users can refresh their plugin. The standalone skill ZIP includes the compiled engine; its entrypoint is `node /path/to/understand-code/scripts/run.mjs`. Neither installable form requires a TypeScript compiler. See the [setup and migration guide](https://github.com/bpstr/understand-code/blob/v2.0.0/INSTALL.md) for all installation routes and PATH considerations when replacing a 1.x Python CLI.

Existing evidence/state and the v1 exchange format remain supported. Python files remain analyzable source text; exact Python AST extraction is replaced by conservative declaration candidates labeled `INFERRED` with an explicit limitation. No target-language runtime is invoked.

## Release artifacts and validation

Download the plugin ZIP, standalone skill ZIP or installable npm `.tgz`, and check their hashes against `SHA256SUMS`. Publication is gated by the prepared offline test and package-validation matrix on Node.js 22, 24 and 26. Packaged bootstrap/verify/status and offline npm installation run with no Python on PATH. The release targets the exact validated commit; it does not overwrite an existing tag or publish to the npm registry.

All behavioral evidence in automated checks comes from prepared fixtures. No live-provider evaluation, paid inference, target-application execution or production qualification is claimed.
